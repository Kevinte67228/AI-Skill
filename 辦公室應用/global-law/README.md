## 摘要

global-law 專案嘗試將全球各國的法律文本以 Git 儲存庫的形式管理，每個國家記錄為一個子模組，每次提交代表一項法律的生效。這為法律研究者、政府機構或任何需要追蹤法律變革的人提供了一個創新且透明的法律版本控制解決方案。
