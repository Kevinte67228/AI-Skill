## 摘要

Skill Recorder 是一個桌面應用程式，能夠錄製螢幕上的工作會話，並利用GitHub Copilot CLI將其重構為意圖和有序步驟，進而為Microsoft Scout、Copilot Cowork或Copilot Studio構建可重用的技能或自動化。它適合希望將日常重複性任務自動化、提高工作效率的專業人士。該工具展示了AI在提升個人生產力方面的巨大潛力。
