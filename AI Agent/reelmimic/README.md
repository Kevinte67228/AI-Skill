## 摘要

reelmimic 是一個 AI 代理系統，能分析用戶喜愛的影片風格，並由 AI 團隊（如 Claude Code 或 Codex）規劃、製作並審核生成相同風格的新影片。它為個人和創作者提供了一個智能化的影片內容生成和編輯解決方案。
