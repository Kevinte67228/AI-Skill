這是為DeepSeek Harness (DSH)設計的終端文字使用者介面(TUI)外掛，提供Claude Code風格的全螢幕互動體驗。它為偏好命令列操作的開發者提供了一個高效且視覺化的DSH代理管理工具，補足了官方在TUI方面的空白。
