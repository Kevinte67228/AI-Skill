## 摘要

這個專案旨在讓 AI（如 Codex）透過 USB 接口控制真實的 iPhone，實現引導安裝、App 自動化操作及實時螢幕互動等功能。它為開發者提供了一個強大的工具，用於探索 AI 驅動的行動裝置自動化和測試。
