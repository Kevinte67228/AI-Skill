## 摘要

GoLive Skill 是一個開源的代理技能，協助將AI代理產品部署上線，涵蓋託管、資料庫、域名、電子郵件和支付等環節。它提供一套從偵測到驗證的自動化流程，讓代理構建的產品能快速投入使用。
