## 摘要

這個專案為DeepSeek Harness (DSH)的網頁介面提供了豐富的外掛和皮膚，包含任務看板、Git圖形、遠端行動介面等多項功能。它旨在提升DSH用戶的操作體驗和客製化程度，讓AI代理的管理更加直觀和高效。
