## 摘要

REAP 專案收集了用於 REA（Reverse Engineer Anything）的提示詞，旨在幫助用戶充分利用 REA 的能力進行程式逆向工程、複製或分解軟體。它提供了實用的策略和範例，讓使用者能更有效地引導 AI 代理完成複雜的分析任務。
