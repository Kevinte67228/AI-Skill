## 摘要

agent-autoloop 讓命令行 AI 代理能在後台自主執行任務，只有遇到不確定的情況才會尋求使用者介入。這大大提升了自動化工作的效率與靈活性，使得 AI 代理能更聰明地協助使用者處理複雜流程。
