## 摘要

cn 是一個全新的引擎，用於 Tailwind CSS 類別的合併與衝突解決，它取代了 tailwind-merge 和 clsx 並提供更快的效能。這個工具提升了前端開發者使用 Tailwind CSS 的效率與體驗，對於追求高效能和簡潔程式碼的開發者來說，是一大福音。
