# Skills 中文命名對照表

以下技能原始碼來自 https://github.com/emilkowalski/skills (MIT License)，
已重新以中文命名資料夾，方便一眼辨識用途。

| 中文名稱 | 原始英文名 | 說明 |
|---|---|---|
| 动画制作 | animate | 從零開始建立動畫（曲線、時長、屬性） |
| 动画术语指南 | animation-vocabulary | 用正確術語跟AI溝通，做出更好的動畫 |
| 苹果设计规范 | apple-design | 依據Apple WWDC設計原則做界面 |
| 设计工程综合技能 | emil-design-eng | 動畫為主，兼顧設計建議的綜合技能 |
| 动画机会侦测 | find-animation-opportunities | 找出UI中適合/不適合加動畫的地方 |
| 动画全面审查改进 | improve-animations | 審查整個專案的動畫，產出優先排序改進計劃 |
| UI函式库选择 | pick-ui-library | 根據需求挑選合適的UI元件庫 |
| UI原型快速制作 | prototype | 快速做出多個UI版本，即時比較挑選最佳版本 |
| 动画品质审查 | review-animations | 依照嚴格規則審查動畫作品品質 |
| GitHub批次部署工具 | github-batch-deploy | 透過Git Data API打包多檔案為單一commit推送 |
