## 摘要

M3E Canvas 允許用戶在瀏覽器中設計 Material 3 的表達性螢幕介面，並將其轉換為程式碼提示。它簡化了 UI/UX 設計到程式實作的過程，對於希望快速原型設計並生成程式碼片段的開發者來說，是一個實用的工具。
