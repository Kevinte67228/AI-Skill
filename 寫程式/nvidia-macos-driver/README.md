## 摘要

這個專案為 macOS 15 Sequoia 上的 NVIDIA GeForce RTX 顯示卡提供了 Metal 驅動程式，支援 Intel 和 OpenCore 環境。它填補了 Mac 用戶在特定硬體支援上的空白，對於需要使用 NVIDIA GPU 的開發者和用戶來說是個重大突破。
