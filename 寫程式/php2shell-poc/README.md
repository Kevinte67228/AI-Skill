## 摘要

Php2shell-poc 專案針對 PHP 的 `session.upload_progress` 漏洞，提供了多條預認證遠端程式碼執行 (RCE) 鏈，並附帶了 Suricata、Sigma、ModSecurity 的檢測規則。它對資安研究人員了解並防範 PHP 相關的潛在威脅具有重要的參考價值。
