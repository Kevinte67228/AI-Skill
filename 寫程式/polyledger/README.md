## 摘要

Polyledger 是一個可恢復的 Polymarket 索引器，能將來自 Polygon 鏈上的訂單簿市場元數據和交易數據整合到一個 DuckDB 檔案中，並可透過 SQL 查詢。它簡化了區塊鏈數據的分析與管理，對於區塊鏈開發者和數據分析師來說，是一個高效的數據處理工具。
