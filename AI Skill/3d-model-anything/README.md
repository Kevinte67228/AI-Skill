## 摘要

3D-Model-Anything 專案利用 iPhone 的 LiDAR 和照片數據，重建可編輯的 Three.js 虛擬房間，並能在瀏覽器中進行探索。它提供了一個創新方式來捕捉真實世界空間並轉化為數位模型，對於擴增實境、室內設計或遊戲開發等領域具有潛在應用價值。
