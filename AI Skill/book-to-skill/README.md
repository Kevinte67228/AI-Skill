## 摘要

這是一個將任何技術書籍的 PDF 檔案轉換成 Claude Code 技能的工具，讓知識能被 AI 代理學習、參考與應用。它值得關注，因為它能將大量非結構化文本資料轉化為可操作的 AI 技能，極大地擴展了 AI 代理的知識庫與實用性。
