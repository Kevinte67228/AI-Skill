## 摘要

universal-modder 專為遊戲模組開發設計，提供工具和技能讓 AI（如 Claude Code）能對任何 PC 遊戲進行偵察、逆向工程、內容生成及遊戲內測試。它極大地簡化了遊戲模組的創建過程，讓非專業人士也能參與其中。
