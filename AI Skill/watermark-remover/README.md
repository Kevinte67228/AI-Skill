## 摘要

Watermark Remover 是一個旨在清除多種來源的 AI 浮水印的工具，支援清理多種檔案格式中的 Unicode 文字、統計改寫鉤點及 C2PA 中繼資料。它對於保護數位內容的原始性、移除不必要的 AI 痕跡具有重要價值。
