## 摘要

這個工具旨在移除多供應商的AI溯源標記，處理圖像、文件等多種格式中的Unicode文本衛生、統計重寫鉤子及C2PA元數據。對於需要處理AI生成內容的隱私、版權或數據清理任務的用戶來說，它提供了一個關鍵的解決方案。
